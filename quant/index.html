Quant Platform

Everything built in this project: a Python platform for researching, backtesting and paper trading US and UK markets, with the reports it produced and a page you can play with. Paper trading only: there is no live trading, by design.

Run it yourself

git clone https://github.com/thanhnguyen77-cr/portfolio-.git
cd portfolio- && git checkout claude/bold-fermi-wt58n7
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,yfinance]"
quant demo --out demo-reports

Nothing here claims a strategy makes money or that the code is free of errors. Every report ends with the assumptions behind its numbers. Not investment advice.
