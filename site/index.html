CLAUDE CODE PLUGIN · TRADINGVIEW + ALPACA

An 11-agent trading desk for Claude.

Eleven agents scan your TradingView watchlist, plan the best setup and backtest its rule over years of history after fees. They size the trade with a capped Kelly Criterion, watch the news, set alerts, and place a paper order on Alpaca. A risk manager has the final veto, and a hook enforces it.

Not financial advice. This is a decision-support and paper-trading tool. Backtests describe the past, stops can gap, and you are responsible for every order. The desk starts in paper mode and cannot switch itself to live trading.

How a trade flows

Each step writes its results to files and has a gate. The desk stops at the first gate that fails, and "no trade" is a normal, frequent outcome. Every number comes from a connector or a tested Python script, never from the model's head.

The eleven agents

Each agent has one job and a written procedure. Only the broker can touch orders; the other ten have order tools removed.

Onboarding

trader-onboarding

Turns your budget, cash to keep aside and max per stock into validated money rules. It also checks the connectors.

Market regime

trader-market-regime

Decides whether the market favours new longs at full size, half size or none.

Screener

trader-screener

Filters your watchlist down to the strongest setups and shows why the rest were cut.

Analyst

trader-analyst

Writes one precise plan with levels set by ATR and price structure, the reasoning behind it, and its invalidation conditions.

Backtester

trader-backtester

Tests the rule behind the plan, not just one chart, and returns an honest verdict.

Position sizer

trader-position-sizer

Sizes with capped, fractional Kelly. It usually recommends fewer shares than you'd expect.

News desk

trader-news-desk

Tracks earnings dates, filings and headlines, with a source for every item. Reports only what changed.

Alerts

trader-alerts

Creates TradingView alerts at your levels. If the connector can't create them, it gives you exact manual steps.

Risk manager

trader-risk-manager

Has veto power. Issues a single-use approval ticket only when every check passes.

Broker

trader-broker

Sends exactly what was approved, as a bracket order, or sends nothing at all.

Journal

trader-journal

Keeps the record straight and tells you whether your edge is real.

Built to say no

Most trading bots are built to trade. This desk is built to stop bad trades.

Lock 1 · Chat

You confirm every order

The desk shows the full order card and waits for an explicit yes to that exact order. Any change starts over.

Lock 2 · Claude Code

Permission prompt

Keep Alpaca's order tools off auto-allow, and Claude Code asks you again before the call runs.

Lock 3 · Hook

Order guard

A PreToolUse hook blocks any order that has no matching, unexpired, unused risk-manager ticket. It also blocks entries without a protective stop.

  • Paper first. Live trading needs two deliberate human edits: one in the Alpaca connector and one in profile.json. The agents can't make either change.
  • No made-up data. Prices, indicators, dates and headlines must come from a connector or a script, with the source named.
  • No curve-fitting. Agents may not loosen filters, lower costs or tweak parameters until something passes.
  • Long-only US stocks and ETFs. Options and crypto orders are always blocked.

Install

Choose Opus 5.5 with /model, install the plugin, then type "install skill". The desk sets up its workspace, asks for your money rules and checks your connectors.

Claude Code plugin · recommended

Installs the skill, all 11 agents and the order-guard hook.

/plugin install trader --marketplace thanhnguyen77-cr/portfolio-

On older Claude Code versions:

/plugin marketplace add thanhnguyen77-cr/portfolio-
/plugin install trader@portfolio-trader

Standalone skill

Download trader-skill.zip, then either:

  1. unzip it into ~/.claude/skills/ and type "install skill" in Claude Code. This installs the agents and the hook; or
  2. upload it in claude.ai under Customize → Skills. There Claude plays each role in turn, and code execution must be on.

Connect Alpaca (paper)

Use free paper-trading keys from the Alpaca dashboard. Name the server alpaca.

claude mcp add alpaca --scope user \
  -e ALPACA_API_KEY=<paper key> \
  -e ALPACA_SECRET_KEY=<paper secret> \
  -e ALPACA_PAPER_TRADE=true \
  -- uvx alpaca-mcp-server

Connect TradingView

Add the TradingView connector in Claude's connector settings. It may need a paid TradingView plan. The agents find its tools by searching, so different connector versions work. If one is missing, the desk falls back to Alpaca data and manual alert steps.

The maths, in the open

All calculations are standard-library Python with unit tests. Agents run the scripts; they never do the arithmetic themselves.

Kelly, handled with care

With a hard stop, a trade loses about 1R or wins about b·R. Kelly's fraction of capital to risk is:

f* = p − (1 − p) / b
  1. The win rate p is shrunk to its 1-sigma lower bound, so small samples count for less.
  2. The desk uses ¼ of full Kelly, scaled by the market regime.
  3. The result is capped by max risk per trade, max per stock, the cash reserve and total exposure. Usually the 1% risk cap decides the size.

Backtest verdicts

Entries fill at the next open plus slippage. If a bar touches both stop and target, the stop counts first. The last 30% of history is held out.

PASSPositive after costs and out of sample, robust to nearby settings, ≥ 0.1 R per trade.
INSUFFICIENT_TRADESFewer than 30 trades; add peers or history.
MARGINALPositive, but too thin to survive real execution.
FRAGILEWorks only at these exact settings, which suggests curve-fitting.
FAIL_OOSWorked in the past, but not recently.
FAILNo edge after costs.
